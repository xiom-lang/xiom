# v0.64.5

## Summary
A correctness release: the thread gateway closes with byte-exact joins, 128-bit and unsigned integer semantics land, aggregates escaping confined blocks stay valid, and a broad resolution sweep removes name, constant and import hazards.

## Highlights

### Spawned threads return their exact results
kind: fix
Joining a spawned worker returns its value exactly: pointer-holding struct fields keep byte-pointer arithmetic through locals and method receivers, so the result read is correct, and confined allocation rounds become ordinary main-memory pointers instead of spinning.

### Wide integers and unsigned ordering
kind: compiler
Native 128-bit values now live correctly inside vectors and structs, and unsigned 64-bit values compare, widen, divide and take remainders with full-width semantics: values with the top bit set order, widen and divide exactly instead of behaving signed.

### Aggregates escaping confined blocks
kind: fix
A struct or vector returned from a confined block is copied to ordinary memory before the guard arena resets: inline vector fields stay valid, a push-tail arm no longer mis-arms the return path, and callers read live data instead of released arena bytes.

### Names, constants and imports resolve exactly
kind: compiler
A broad resolution sweep: enum variants no longer collide with geometry names, soft-keyword field names parse, constants re-export through public use, shadowing constants no longer hang the build, pointer spellings resolve at call sites, and checks stay enforced on optimized builds.

## Breaking changes
- None.

## Known issues
- Comparing containers with equality operators is pointer identity: two equal vectors compare unequal, and equal results containing vectors compare unequal; deep container equality is queued.
