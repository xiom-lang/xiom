# v0.65.6

## Summary
Memory-heavy Vec, JSON, and aggregate paths reclaim their allocations, the checker enforces init-once bindings and seven spec rules, and optional tier-3 lint ships with a clean corpus.

## Highlights

### Vec, JSON, and aggregate memory reclamation
kind: fix
Rebinding an owned Vec now frees the data pointer read from the current header, so a push that reallocates before the rebind can no longer double-free. JSON parse trees, builder containers, and scratch buffers are reclaimed under ownership and borrow contracts while literal keys and borrowed string leaves stay untouched. A provably unique aggregate field or whole-struct overwrite now frees its old payload; aliased and trace-ring shapes stay leak-only.

### Init-once bindings and all seven spec rules
kind: language
The checker now enforces let and const immutability as init-once: a deferred let may be initialized once, while a reassignment of an initialized binding, const, or field is rejected. Seven audited spec gaps are hard diagnostics with positive controls and no ignored tests: loop control placement, duplicate parameters, duplicate struct fields, duplicate pattern bindings, CTFE-evaluable const initializers, fixed-width integer bounds, and init-once mutability.

### Opt-in tier-3 lint with a clean corpus
kind: tooling
Tier-3 warnings W010 through W015 are available behind the opt-in strict lint flag and stay off by default. The example and regression corpus was triaged to zero tier-3 findings, so a strict run is clean without changing default builds.

### Sanitizer tagging and relay correctness fixes
kind: compiler
Address sanitizer builds now tag generated IR and bypass the guard arena, and the guarded allocator recycles freed blocks instead of retaining them until block exit. By-reference function parameters are enforced, the macOS typed memset lowering is fixed, the HTTP server frees its parse buffers, and W000, exhaustiveness, the explain flag, Int plus Str, and mixed to_str conversions behave consistently.

## Breaking changes
- None.

## Known issues
- The libc user-symbol mangling change is deferred to a later release.
- The C-PULSE aggregate-return residual is deferred: loop-body and container drops are reclaimed, but an unconsumed returned aggregate can still retain memory.
- Four formatter smoke programs still corrupt the heap in a build and finish cycle; this regression predates this release and is under investigation.
- macOS and BSD event-loop support still returns an explicit error until the kqueue backend lands.
