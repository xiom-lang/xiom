# v0.65.5

## Summary
Memory-leak release with a bounded 600-frame editor soak and ownership/drop fixes across Vec, Str, Map and removal containers, plus the stdlib pin, with no breaking changes.

## Highlights

### Editor 600-frame soak under 2 GB
kind: fix
The engine 600-frame soak now completes at 419/826 MB WS/private with a 0.037 MB/frame slope; the previous build was killed at the 2 GB cap. The graph serializer no longer re-serializes the xg graph every frame, and the compiler ownership and drop slices plus the engine resource work are validated together.

### Vec and Str overwrite and ownership reclamation
kind: compiler
Fresh reassignment of an owned Vec local frees the replaced data at the assignment. The borrows_vec attribute keeps caller ownership for non-retaining Vec call arguments and trusts a callee's own pointer exports; inline aggregate frame literals keep owned field locals' drops. Typed Str element leaves and Vec of Str element payloads are freed, and replaced Str rebind buffers are reclaimed at scope exit.

### Map, Set and removal payloads
kind: compiler
The owns_return map and set constructors plus consumes_str consuming mutators free owned Vec of Str field elements at exit. Removal and reorder methods keep the element tag, and a provably dead removed element is freed at the binding. The borrowing API remains for literal or borrowed keys.

### Stdlib v0.65.5 pin
kind: stdlib
The compiler pins the v0.65.5 stdlib package, including the string copy-from-malloc fix, the persistent worker pool, and the consuming Map mutators. No breaking changes.

## Breaking changes
- None.

## Known issues
- Field/whole-struct aggregate overwrite-drop (REL-2117) remains leak-only; it needs an opt-in aggregate contract.
- JsonValue and enum JSON tree retention (REL-1704) remains a compiler slice.
- The compiler binary reports v0.65.5; the stdlib package is 0.65.5 and its COMPILER_VERSION remains v0.65.4 as published.
