# v0.65.3

## Summary
A correctness hotfix for the three release blockers: the published orbitdb carve, the stdlib SSE probe, and the transport Vec[Vec]/UDP suites.

## Highlights

### Aggregate ownership across literals, returns and helpers
kind: compiler
Nested struct literals, implicit tail returns and leaf-helper returns (ok_outcome(done)) now transfer the owned Vec fields; a projected Vec field moves its source aggregate, and a by-value aggregate passed to a retaining callee is moved. The orbitdb carve and the transport Vec[Vec]/UDP suites are green.

### Aggregate Vec fields re-read at drop
kind: compiler
A struct field's data pointer is loaded at drop time instead of being captured at the binding, so growing the field in place no longer double-frees (p_wave162). The borrowed-but-grown aggregate UAF is covered by the implicit-return transfer above.

## Breaking changes
- None.

## Known issues
- Map/JSON/enum-tree retention (REL-1704) is the next memory slice.
- Vec[Str] element strings and removal containers are not yet reclaimed.
- By-value aggregate parameters are caller-transferred for retaining callees; callee-side parameter drops remain future work.
