# v0.64.6

## Summary
A correctness release over the v0.64.5 waves: tuple naming is canonical in every position, catalog binding and import surfaces resolve exactly, scalar-named enum variants stop shadowing builtins, imported-type globals keep their layouts, the clang-18 linux miscompile is fixed, and the dependency C pipeline compiles through an object cache.

## Highlights

### Tuple names are canonical everywhere
kind: compiler
Inline Str-producer elements and enum-element tuples keep ONE tuple spelling across construction, signatures and reads: the m334/m336 fixes close the C-ORBIT-12 enum-error case and the 1941 inline-from_utf8 case, so no site can build one name while another expects a different one.

### Scalar-named enum variants stop shadowing builtins
kind: fix
A module with a variant named Str (or any scalar name) no longer hijacks the builtin qualifier: Str::from_utf8 and friends resolve as builtins again, while non-scalar variant precedence from m315 stays intact.

### Imported-type globals keep their layouts
kind: fix
Module-level vars declared with dotted imported-type spellings (module alias or full path) resolve to the registered struct key: multi-field struct globals store and read every field instead of an i64 slot, and the unknown-type defaulting warning is gone.

### Catalog binding and import surfaces resolve exactly
kind: fix
Bare calls in secondary modules bind the imported submodule owner instead of a same-leaf parent (with deterministic resolution when owners collide), pub-use re-exported consts reach catalog bodies, and recoverable parse errors in imported modules surface as P001 with a suppression note instead of a downstream undefined-variable cascade.

### clang-18 linux miscompile fixed (optimizer stage)
kind: fix
The linux-x64 /search miscompile was pinned to clang-18's X86 Avoid Store Forwarding Blocks pass interleaving an overlapping copy: native x86_64 builds driven by clang 18 now disable that pass (IR and ABI unchanged; every other toolchain's invocation byte-identical).

### Dependency C builds compile once
kind: compiler
Dependency port.args.json c_sources now compile through an object cache (same key scheme as the runtime object cache) and link from cached objects, and a dependency's declared --timeout floors the watchdog at consumer builds: heavy manifests stop recompiling hundreds of TUs on every probe.

### E001 move coverage and clause payload rebinds
kind: compiler
The borrow pass now resolves declared types, so call-initialized locals and field projections report use-of-moved-value (annotated/unannotated parity, scalar exemption kept), and contract clause payload rebinds are layout-aware for concrete monomorphs -- inline aggregate payloads read their real fields instead of an inttoptr-as-handle.

### Darwin toolchain pair
kind: fix
The pinned stdlib (stdlib-v0.64.6) carries the win64 fp128 convention split and the darwin fixes verified in the darwin stream; the compiler side ships the memset declare from the same line of work.
