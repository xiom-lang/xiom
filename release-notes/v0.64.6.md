# v0.64.6

## Summary
Canonical tuple naming, import/catalog resolution, builtin-shadow and imported-global fixes, the clang-18 linux fix, cached dependency C builds, and the borrow/contract batches -- on the stdlib-v0.64.6 pin.

## Highlights

### Tuple names are canonical everywhere
kind: compiler
Inline Str-producer elements and enum-element tuples keep ONE tuple spelling across construction, signatures and reads: no site can build one name while another expects a different one, closing the enum-in-tuple link failure and the inline-from_utf8 mismatch in the same family.

### Builtins stop being shadowed; imported globals keep layout
kind: fix
A module with an enum variant named Str no longer hijacks the builtin qualifier, so Str::from_utf8 works there again. Module-level vars with dotted imported-type spellings resolve to the registered struct key: multi-field globals store and read every field, without the defaulting warning.

### Catalog binding and import surfaces resolve exactly
kind: fix
Bare calls in secondary modules bind the imported submodule owner instead of a same-leaf parent (deterministic on collisions), pub-use re-exported consts reach catalog bodies, and recoverable parse errors in imported modules surface as P001 instead of an undefined-variable cascade.

### clang-18 linux miscompile fixed (optimizer stage)
kind: fix
The linux-x64 /search miscompile was pinned to clang-18's X86 Avoid Store Forwarding Blocks pass interleaving an overlapping copy: native x86_64 builds driven by clang 18 now disable that pass (no IR/ABI change; every other toolchain's argv byte-identical).

### Dependency C builds compile once
kind: compiler
Dependency port.args.json c_sources now compile through an object cache and link from cached objects, and a dependency's declared --timeout floors the watchdog at consumer builds: heavy manifests stop recompiling hundreds of TUs on every probe.

### Bindings, moves, clauses and field chains
kind: compiler
The borrow pass resolves declared types (call-init and field-projection moves now warn), contract clause payload rebinds are layout-aware for concrete monomorphs, and inferred bindings from generic-substituted field elements keep their element type instead of degrading to a pointer-as-Int slot.

## Breaking changes
- None.

## Known issues
- Comparing containers with equality operators is pointer identity: two equal vectors compare unequal, and equal results containing vectors compare unequal; deep container equality is queued.
