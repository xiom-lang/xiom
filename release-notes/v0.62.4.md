# v0.62.4

## Summary
A correctness patch: the script cache, constant tables, nested modules,
match-arm code generation, and unsigned comparisons are fixed.

## Highlights

### Script cache runs keep stdin
kind: fix
A warm script-cache hit ran the cached program with closed input, so a
second run of a program that reads from the terminal saw nothing; the
--no-cache and --jit flags were also ignored on that path. Cached runs now
inherit stdin and the flags are honored.

### Constant tables with strings and structs
kind: fix
Module-level constant arrays of strings or structs were not materialized
correctly: struct fields read as zero and string lengths returned garbage.
They are now real constant globals, and integer tables are unchanged.

### Nested modules and same-name payload types
kind: fix
A module nested under another module (for example a package tests module
importing its package) saw none of the parent module's exports. A struct
type sharing a name with an enum variant was also built as the enum and
produced broken code; the type now wins inside its module.

### Match arms and unsigned comparisons
kind: fix
An uninitialized local assigned inside match arms could crash or read
garbage. An inline comparison of a module-qualified unsigned call result
misread values with the top bit set. Constant-valued match arms never
matched and always fell through to the default arm. All three are fixed.

### Doctor version checks
kind: tooling
The doctor no longer warns when the standard library's own release line
differs from the compiler's patch version, and tag-shaped standard-library
pins are not compared as versions.

### Compile-phase timings
kind: tooling
Setting XIOM_TIMINGS=1 prints per-phase compile times to stderr (parse,
check, borrow, codegen), for profiling builds and benchmarks.

## Breaking changes

- None.

## Known issues

- LZ4 block compression can read an empty result in some larger programs; the cause is isolated and scheduled for the next minor release.
- The contract verifier emits malformed SMT for some obligations (undeclared symbols, duplicate named expressions), so those checks report unknown instead of proving; scheduled for the next minor release.
