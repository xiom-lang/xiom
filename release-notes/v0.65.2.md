# v0.65.2

## Summary
A memory-and-ABI release: byte vectors use packed slots, arm64 contracts compile, and the first non-Vec ownership slice drops bound strings.

## Highlights

### Borrowed and moved vectors are reclaimed
kind: compiler
Fresh vectors passed by reference to ordinary functions, or moved into a struct literal, stay owned by the caller and are freed at scope exit. Constructors that return a struct use the owns-return contract; the editor frame path no longer grows per frame.

### arm64 contracts compile
kind: fix
The contract evaluator loads a Result payload with its real field type, so Result[Str, Error] contracts no longer fail LLVM verification on arm64. The arm64 packaging gate is unblocked.

### Inline Result payload indices
kind: fix
An inline Result.value[i] in a concatenation now reads the element's real type instead of formatting its pointer bits. The bound workaround is no longer needed.

### Bound strings are reclaimed
kind: compiler
Freshly built local strings from concatenation and numeric formatting are freed at scope exit. String-heavy loops no longer grow per iteration; Map, JSON, and HTTP follow.

## Breaking changes
- None.

## Known issues
- Map, JSON enum-tree, and HTTP request buffers still retain; the next retention slices cover them.
- Strings returned from functions are not yet dropped; only fresh local bindings are.
- Microcontroller targets use a bump allocator and do not support exceptions.
