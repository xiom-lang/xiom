# v0.62.2

## Summary
A performance and correctness release: thread-safe code stops paying a
safety tax, constant tables stop bloating outputs, and module resolution
gets several fixes.

## Highlights

### Trusted atomics skip the safety trampoline
kind: compiler
Hot loops built on the standard library's atomic primitives no longer pay
the unsafe-confinement trampoline on every operation. Trusted primitives
compile directly, so the thread-safe queue benchmark drops from seconds
to milliseconds while the confinement guarantees still guard everything
else.

### Constant tables compile once, not per use
kind: compiler
A module-level constant array is emitted once as a read-only global
instead of being rebuilt on the stack at every reference. Large lookup
tables (tens of thousands of entries) shrink both code size and compile
time dramatically.

### Byte buffers grow past 16 MB
kind: fix
The vector growth guard capped buffers at about 16 million elements, so a
byte vector could not hold a 20 MB file. The ceiling is now 4 billion
elements (32 GB for byte buffers); allocation failure remains the real
limit.

### Strings built inside methods are correct
kind: fix
A vector-of-strings field read inside a method could compile to integer
arithmetic on pointers, producing garbage strings or a crash.
Concatenation and accumulation in method bodies now call the string
runtime like everywhere else.

### Sibling imports work under the run command
kind: fix
Running a script now resolves modules next to the script exactly like
checking it does; previously the temporary working copy hid the script's
directory from the module catalog.
