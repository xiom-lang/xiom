# v0.65.7

## Summary
String lifetime and comparison handling, nested aggregate reuse, clearer diagnostics, and a recorded stdlib identity make this toolchain more predictable and easier to audit.

## Highlights

### Str lifetimes, comparators, and tuple patterns
kind: language
Returned Str values keep their ownership across match arms, so a fresh string is not freed while it is still in use. Str comparators behind function-typed parameters compare contents even when passed by value, and tuple patterns over Option and Result bind every nested element.

### Nested aggregates and aggregate returns reclaim memory
kind: fix
Copying, modifying, and writing back a nested aggregate field no longer emits an invalid vector extractvalue, so a module-level Vec of struct values compiles. Aggregate returns through Option and Result free their owned payload containers, and large allocations request transparent huge pages on Linux.

### Clearer diagnostics and a recorded stdlib identity
kind: tooling
Windows build and check failures now report a diagnostic instead of exiting silently. Every release archive carries a stdlib commit file with the exact bundled commit, and the release publishes a top-level stdlib identity asset that is checksummed with the other downloads.

## Breaking changes
- None.

## Known issues
- The libc user-symbol mangling change is deferred to a later release.
- Selfhost phase 8 remains incomplete; no bootstrap binary ships in this release.
- Tier-3 lint stays opt-in; making it default-on is a separate decision.
