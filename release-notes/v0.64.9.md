# v0.64.9

## Summary
Vector and payload ABI fixes, shared dependency objects, dependency build flags, and a fast process exit, with the matching stdlib pin.

## Highlights

### Vector and adapter typing
kind: fix
Callee return types now drive Vec element inference and generic adapter calls. The XVC-C-22 PQ codebook drift and second-call access violation are gone, and MapIter.max plus ZipIter.find keep their concrete types.

### Payload and function values
kind: fix
Boxed Option and Result Str payloads, stored function values, and borrowed enum matches bind by value. Tuple-returning handlers with reference parameters return the full tuple instead of a pointer.

### Enum equality and dependency keys
kind: fix
Struct equality on a plain enum now compares the discriminant, so log and serialize builds link. Dependency objects use one consumer-neutral key, so multi-target builds stop rebuilding the full vendored set.

### Dependency port args and fast exit
kind: fix
Package manifests now expose their deps, so an installed package receives its dependency build args and vendored sources. An opt-in fast exit skips process teardown while preserving guard-fault diagnostics.

## Breaking changes
- None.

## Known issues
- The selfhost compiler remains a work in progress and is not part of this toolchain release.
- Dependency objects use a pinned optimization level and are not sanitizer-instrumented.
- The 1M orbitdb exit A/B and the engine dependency-key re-measure are post-release checks.
- A 16 GB Job Object build hang and a JSON numeric service read are still under reporter re-test.
