# v0.65.0 execution checklist

Owner: compiler lane. Status: IN DEVELOPMENT. Gate:
`docs/RELEASE_GATE_v0.65.0.md`. v0.64.9 is withdrawn; production pin stays
v0.64.8 until v0.65.0 is green.

## P0 -- correctness (no candidate before these)

### Nested enum/pattern payloads (1615/1645/1243/1451/1550 family)

- [x] `stmt.rs`: arm check for `Some(inner)`/`Ok(inner)`/`Err(inner)`
      recurses when `inner` is `Pattern::Variant`: load the inner enum
      payload, check its discriminant, and branch only on a match.
- [x] `stmt.rs` binding: `bind_variant_payload_fields` +
      `enum_payload_value_ptr` bind Float64/Float32/Str/Vec/struct fields,
      with `local_xiom_types`, `local_boxed_struct`, and
      `local_vec_handle` tracking.
- [x] Cover `Some(Num(f64))`, `Result[Inner, Str]` `Ok(Num(f64))`,
      nested `Text(Str)`, and `Some(JsonValue.Number(f64))` in debug and
      release-shaped probes.
- [x] Regression fixture + e2e lock `m1615_nested_enum_payloads`
      (exact values, JSON included).
- [x] No regression for top-level `Pattern::Variant`, borrowed enum
      matches (1731), or boxed Str payloads (2045).
- [ ] 1645: direct `Err(E.Bad("..."))` pushed into `Vec[Result[Str, E]]`
      still loses the Str payload (`direct=` empty). This is a separate
      Vec-push boxing path, not nested-pattern lowering. Add the fixture
      and fix before the release.

### Safe generic substitution (m372/1451/1550)

- [x] Bisect artifact confirmed: `d04cd3265` explicit type-arg
      substitution breaks m372; reverting it breaks m1520.
- [x] Generic pointee base canonicalization (`Pair[Int]` -> `Pair`) plus
      the LLVM pointer fallback and pointer-local inference; the receiver
      shortcut no longer preempts `ptr.read`/`ptr.write`.
- [x] Keep `_max_via[U]` -> `_max_via_Int` and the
      `EnumerateIter[Int].map` e2e chain green; m372 is 42/42.
- [x] e2e locks for m372/m1520/m1550 are green.
- [ ] True tuple-returning `p_iter_enumerate_tuple` (`em[1].0`) still
      fails; finish the payload/stride fix and add its e2e.
- [ ] Add a unit test for the substitution guard.
