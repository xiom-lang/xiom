# v0.65.0 execution checklist

Owner: compiler lane. Status: IN DEVELOPMENT. Gate:
`docs/RELEASE_GATE_v0.65.0.md`. v0.64.9 is withdrawn; production pin stays
v0.64.8 until v0.65.0 is green.

## P0 -- correctness (no candidate before these)

### Nested enum/pattern payloads (1615/1645/1243/1451/1550 family)

- [ ] `stmt.rs`: arm check for `Some(inner)`/`Ok(inner)`/`Err(inner)` must
      recurse when `inner` is `Pattern::Variant`: load the inner enum
      payload, check its discriminant, and branch to the arm only on a
      match.
- [ ] `stmt.rs` binding: for a nested variant, bind each field from the
      inner enum's variant metadata, with Str/Float64/Float32/Vec/struct/
      boxed-aggregate representation conversions, `local_xiom_types`, and
      `local_boxed_struct`/`local_vec_handle` tracking.
- [ ] Cover `Some(Num(f64))`, `Result[Inner, Str]` `Ok(Num(f64))`,
      `Err(E.Bad(Str))` in `Vec[Result[Str, E]]`, and
      `Some(JsonValue.Number(f64))` in release builds.
- [ ] Regression fixtures + e2e locks; add the local 15-line nested-enum
      fixture and the JSON probe; assert exact values, not just rc.
- [ ] Verify no regression for top-level `Pattern::Variant`, borrowed
      enum matches (1731), and boxed Str payloads (2045).

### Safe generic substitution (m372/1451/1550)

- [ ] Bisect artifact confirmed: `d04cd3265` explicit type-arg
      substitution breaks m372; reverting it breaks m1520.
- [ ] Substitute only a **bare generic-param ident** (`T`, `U`, ...),
      never a concrete type string (`Pair[Int]`, `Int`, `Vec[Str]`).
- [ ] Keep `_max_via[U]` -> `_max_via_Int` and the `EnumerateIter[Int].map`
      chain green; keep `m372` at 42/42.
- [ ] Add a unit test for the substitution guard and e2e locks for m372,
      m1520, m1550, and the true `em[1].0` tuple shape.

### Release-compiler parity (the missing v0.64.9 gate)

- [ ] CI job builds `xiom` with the release profile and runs the P0
      probes from the **release** binary.
- [ ] Run the full battery with `target/release/xiom.exe` locally before
      the candidate.
- [ ] Add a test-harness switch so e2e tests can target the release
      binary, not only `target/debug`.

### m1511 transitive dependency port args

- [ ] `dep_port_args`: recurse over `dependency_package_dirs` with a
      visited set and cycle guard; apply each level's `port.args.json`.
- [ ] Two-level installed-layout test: consumer -> fontraster ->
      harfbuzz; assert the harfbuzz vendor source and flags reach the
      consumer.
- [ ] Installed fontraster build with no tree-relative workaround; packages
      can unhold publish after this.

### C07 memory

- [ ] Reproduce the capture probe OOM on v0.64.9 (1.43-1.50 GB) and
      bisect against v0.64.4.
- [ ] Fix or waive with owner approval; add an RSS-ceiling e2e.

### Remaining rows

- [ ] 1531 verified (done); XVC-C-22 verified (done).
- [ ] 1731/1703/1326/2045/1550/1511/1157 locks green on the release
      archive.
- [ ] Triage the older open compiler items; fix or explicitly close with
      reporter agreement (no silent backlog).
